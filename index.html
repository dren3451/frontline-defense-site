Поддержка

Нашли ошибку, пропала покупка или есть идея? Напишите: houseloverbg@gmail.com. Укажите модель устройства, версию iOS и версию игры (главное меню → Настройки).

Покупка не появилась

Главное меню → «Снабжение» → «Восстановить покупки». Золото и наборы для боя начисляются один раз на каждую покупку; если после восстановления их нет — напишите нам.

Прогресс на другом устройстве

Прогресс синхронизируется через iCloud. Войдите на обоих устройствах в один Apple ID и включите iCloud для игры, затем откройте игру на каждом устройстве.

Game Center

Таблицы рекордов и достижения доступны, если вы вошли в Game Center (Настройки iOS → Game Center).

Support

Found a bug, missing a purchase or have an idea? Write to houseloverbg@gmail.com. Please include your device model, iOS version and the game version (main menu → Settings).

A purchase did not arrive

Main menu → Supply → Restore Purchases. Gold and battle packs are granted once per purchase; if they are still missing after restoring, write to us.

Progress on another device

Progress syncs through iCloud. Sign in with the same Apple ID on both devices, keep iCloud on for the game, then open the game on each device.

Game Center

Leaderboards and achievements are available when you are signed in to Game Center (iOS Settings → Game Center).
